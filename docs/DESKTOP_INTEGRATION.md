# 桌面集成

## 当前支持的能力

### 系统通知
- Protocol 使用 Tauri v2 通知插件发送系统级桌面通知
- **专注任务到期**：神圣座位时间到达后，发送"专注时间已到，请确认完成任务"
- **辅助链到期**：辅助链进入确认窗口或待裁决状态时，发送"辅助链已到期，请履约或进入裁决"
- 同一次 session 不会重复发送通知
- 应用重启后，若仍处于到期/待裁决状态，会再次通知一次

### 通知开关
- 位置：设置页 → 桌面通知
- 开启/关闭 toggle 控制
- 开启时自动检查系统通知权限，未授权会提示
- 通知开启后，可点击"测试通知"按钮验证系统通知正常工作
- 若系统权限被拒绝，页面会显示明确提示："系统通知权限未授予，请在系统设置中允许 Protocol 通知。"

### 托盘
- 应用启动后，系统托盘出现 Protocol 图标
- 托盘菜单：**打开 Protocol**（显示并聚焦窗口）
- 当前不提供"退出"菜单项，退出请通过窗口关闭按钮正常退出
- 原因：托盘 `app.exit(0)` 会绕过前端的活跃协议确认流程

### 窗口关闭警告
- 若存在活跃的专注任务（神圣座位）或辅助链（预约），关闭窗口时会弹出确认对话框
- 对话框会列出当前活跃的协议流程及其状态
- 明确告知：关闭窗口不会自动结束协议，重新打开后仍需完成或裁决

## 限制
- 不支持最小化到托盘（Tauri v2 WindowEvent 不包含 Minimized 事件，需要平台特定实现）
- 不支持手机通知、云同步
- 不做系统锁定或强制拦截退出
