# 质量检查清单（QA Checklist）

本文档包含 Protocol 的手动冒烟测试清单。每次发布前应逐项验证。

测试环境要求：已执行 `npm run tauri build` 或 `npm run tauri dev` 启动应用。

---

## 1. 主链管理

### 1.1 创建主链
- [ ] 打开应用，进入「CTDP 链」页面
- [ ] 点击创建新链
- [ ] 填写链名称、描述、触发动作、完成条件、专注时长
- [ ] 填写辅助链触发动作、预约时长、辅助链完成条件
- [ ] 保存后链列表中出现新链

### 1.2 查看链详情
- [ ] 点击链进入详情页
- [ ] 显示链名称、当前长度、最佳长度
- [ ] 显示触发动作、完成条件、专注时长
- [ ] 显示辅助链配置（触发动作、延迟、完成条件）
- [ ] 显示协议边界（判例列表，区分主链判例 / 辅助链判例标签）

### 1.3 编辑链
- [ ] 在详情页可编辑链的名称、描述、触发动作、完成条件、辅助链配置
- [ ] 保存后修改生效
- [ ] 空名称不可保存（有错误提示）

---

## 2. 正式任务（主链神圣座位）

### 2.1 启动正式任务
- [ ] 在链详情页点击「开始正式任务」
- [ ] 确认进入任务进行中状态
- [ ] Dashboard 显示「任务进行中」及链名
- [ ] 全局顶部或底部应显示进行中任务提示

### 2.2 完成任务
- [ ] 在任务进行中点击「完成」
- [ ] 链当前长度 +1
- [ ] 链最佳长度同步更新（若当前 > 最佳）
- [ ] History 中出现 completed 事件
- [ ] Dashboard 状态恢复为「无活动」

### 2.3 中途失败 → 违规清零
- [ ] 启动一个正式任务
- [ ] 选择「中途失败」
- [ ] 选择裁定：违规
- [ ] 可选：选择调试分类（触发动作太重 / 完成条件过高 / 时间太长等）
- [ ] 确认后链当前长度清零
- [ ] History 中出现 failed_reset 事件
- [ ] Dashboard 状态恢复

### 2.4 中途失败 → 判例化
- [ ] 启动一个正式任务
- [ ] 选择「中途失败」
- [ ] 选择裁定：判例化
- [ ] 填写判例标题和描述
- [ ] 可选：选择调试分类
- [ ] 确认后链当前长度不清零
- [ ] 判例库中出现新判例（scope: main_chain）
- [ ] 链详情页协议边界中展示新判例
- [ ] History 中出现 failed_precedent 事件

---

## 3. 辅助链

### 3.1 启动辅助链
- [ ] 在链详情页点击「预约启动」
- [ ] 确认预约已创建
- [ ] Dashboard 显示「预约倒计时」及链名、到期时间
- [ ] 全局顶部或底部显示预约倒计时信息

### 3.2 辅助链履约
- [ ] 在预约确认窗口内点击「履约并进入正式任务」
- [ ] 自动进入正式任务（神圣座位）
- [ ] 辅助链当前长度 +1
- [ ] 辅助链最佳长度同步更新
- [ ] 预约记录变为 fulfilled
- [ ] History 中出现 fulfilled 事件

### 3.3 辅助链到期 → 待裁决
- [ ] 启动一个辅助链
- [ ] 等待确认窗口结束（或手动触发到期）
- [ ] 确认状态变为「待裁决」
- [ ] Dashboard 显示「预约待裁决」

### 3.4 辅助链裁决 → 违约
- [ ] 在待裁决状态下选择「违约」
- [ ] 可选：选择调试分类
- [ ] 确认后辅助链当前长度清零
- [ ] 主链长度不受影响
- [ ] History 中出现 failed_reset 事件

### 3.5 辅助链裁决 → 判例化
- [ ] 在待裁决状态下选择「判例化」
- [ ] 填写判例标题和描述
- [ ] 确认后辅助链当前长度不清零
- [ ] 判例库中出现新判例（scope: reservation_chain）
- [ ] 链详情页协议边界中展示新判例（标签为「辅助链」）

---

## 4. 判例库

### 4.1 查看判例
- [ ] 在链详情页的协议边界区域查看活跃判例
- [ ] 点击判例进入详情页
- [ ] 显示判例标题、描述、作用域、创建时间、来源会话

### 4.2 编辑判例
- [ ] 在判例详情页编辑标题和描述
- [ ] 保存后修改生效
- [ ] 已废止判例不可编辑（有错误提示）

### 4.3 废止判例
- [ ] 在判例详情页点击「废止」
- [ ] 确认后判例状态变为 retired
- [ ] 该判例不再出现在协议边界列表中
- [ ] 历史事件仍保留判例关联信息
- [ ] 二次废止不改变 retired_at 时间

---

## 5. RSIP 定式树

### 5.1 创建定式
- [ ] 进入「RSIP 定式树」页面
- [ ] 创建根定式（填写标题和执行说明）
- [ ] 创建子定式（选择父节点后创建）
- [ ] 树形展示正确，子节点缩进显示
- [ ] formula_events 中出现 created 事件

### 5.2 点亮定式
- [ ] 在定式树中点亮一个非活跃定式
- [ ] 状态变为 active，显示点亮时间
- [ ] formula_events 中出现 activated 事件
- [ ] Dashboard RSIP 摘要中活跃定式数 +1

### 5.3 熄灭定式（含回滚）
- [ ] 创建一个根定式并点亮
- [ ] 在其下创建一个子定式并点亮
- [ ] 熄灭根定式，填写熄灭备注
- [ ] 根定式变为 inactive
- [ ] 子定式自动变为 inactive（递归回滚）
- [ ] formula_events 中出现 deactivated + rollback_child_deactivated 事件
- [ ] History 中显示相关事件

### 5.4 定式复盘
- [ ] 点击定式进入复盘面板
- [ ] 显示生命周期（创建、激活、停用时间）
- [ ] 显示子定式数量、活跃子定式数量
- [ ] 显示回滚事件次数
- [ ] 显示最近一次熄灭备注
- [ ] 显示事件历史列表
- [ ] 可编辑标题和执行说明

### 5.5 编辑定式
- [ ] 在复盘面板中编辑标题和执行说明
- [ ] 空标题不可保存

---

## 6. Dashboard

### 6.1 状态恢复
- [ ] 关闭应用
- [ ] 重新打开应用
- [ ] Dashboard 应正确显示：
  - 链数量
  - 最长链长度
  - 今日完成任务数
  - 活跃协议状态（无活动 / 任务进行中 / 待裁决 / 预约倒计时）
  - RSIP 摘要（总数 / 活跃数 / 最新事件）

### 6.2 状态切换
- [ ] 从「无活动」→ 启动预约 →「预约倒计时」
- [ ] 从「预约倒计时」→ 确认窗口到期 →「预约待裁决」
- [ ] 从「预约待裁决」→ 完成裁决 →「无活动」
- [ ] 从「无活动」→ 启动正式任务 →「任务进行中」
- [ ] 从「任务进行中」→ 完成任务 →「无活动」

---

## 7. History

### 7.1 事件显示
- [ ] 进入「历史记录」页面
- [ ] 显示 CTDP 事件（focus completed / failed_reset / failed_precedent）
- [ ] 显示辅助链事件（reservation fulfilled / failed_reset / failed_precedent）
- [ ] 显示 RSIP 事件（created / activated / deactivated / rollback_child_deactivated）
- [ ] 每条事件显示类型标签、链名/定式名、时间、结果

### 7.2 筛选
- [ ] 按事件类型筛选（focus / reservation / rsip）
- [ ] 按结果筛选（success / failed / precedent）
- [ ] 按链筛选
- [ ] 筛选结果正确

---

## 8. Settings

### 8.1 设置保存
- [ ] 进入「设置」页面
- [ ] 修改默认专注时长
- [ ] 修改默认预约时长
- [ ] 修改辅助链确认窗口时长
- [ ] 关闭应用后重新打开
- [ ] 设置值保持修改后的状态

### 8.2 设置生效
- [ ] 修改默认专注时长后创建新链，验证默认值
- [ ] 修改辅助链确认窗口时长后创建预约，验证确认窗口时间

---

## 9. Build 后检查

### 9.1 安装包启动
- [ ] 执行 `npm run tauri build` 生成安装包
- [ ] 安装应用
- [ ] 启动应用，确认正常启动
- [ ] Dashboard 正常显示
- [ ] 可以进行基本的链创建和任务操作

### 9.2 干净环境测试
- [ ] 在没有 `protocol.db` 的新环境中启动应用
- [ ] 确认数据库自动创建
- [ ] 确认初始设置值正确（专注 25 分钟、预约 15 分钟、确认窗口 3 分钟）
- [ ] 确认无报错或崩溃
