# 质量检查清单（QA Checklist）

本文档包含 Protocol 的手动冒烟测试清单，分为两个层级：

- **Must-run smoke test**：≥ 10 分钟的必跑项目，每次提交前 / 合并前执行
- **Full QA checklist**：完整发布前检查，正式发布前执行

测试环境要求：已执行 `npm run tauri dev` 启动应用（Must-run）；或已执行 `npm run tauri build` 安装应用（Full QA 的 Build 后部分）。

---

# Tier 1: Must-run Smoke Test（约 10 分钟）

每次提交到 master 前必须完成。

## S1. 主链核心路径

- [ ] 创建一条新链（名称、触发动作、完成条件、专注时长）
- [ ] 链出现在列表中，点击可进入详情页
- [ ] 编辑链配置，保存后修改生效

## S2. 正式任务核心路径

- [ ] 在链详情页点击「开始正式任务」，确认进入进行中状态
- [ ] 完成任务 → 链长度 +1，Dashboard 状态恢复
- [ ] 再启动一个任务，选择中途失败 → 违规清零 → 链长度归零

## S3. 辅助链核心路径

- [ ] 启动辅助链（预约），Dashboard 显示倒计时
- [ ] 履约进入正式任务 → 辅助链长度 +1
- [ ] 再启动一个辅助链，等确认窗口结束 → 进入待裁决
- [ ] 裁决为违约 → 辅助链清零，主链不受影响

## S4. 判例库核心路径

- [ ] 启动任务后失败 → 判例化 → 判例出现在协议边界
- [ ] 点击判例查看详情
- [ ] 废止该判例 → 不再出现在协议边界

## S5. RSIP 核心路径

- [ ] 创建一个根定式 → 点亮
- [ ] 创建一个子定式 → 点亮
- [ ] 熄灭根定式 → 子定式自动熄灭（回滚）
- [ ] Dashboard RSIP 摘要数据正确

## S6. 状态持久化

- [ ] 关闭应用，重新打开
- [ ] Dashboard 显示正确的链数量、最长链、今日任务数
- [ ] RSIP 定式状态恢复正确
- [ ] 如有进行中的任务/预约，状态正确恢复

## S7. Check 脚本

- [ ] `npm run typecheck` 通过
- [ ] `npm run check` 通过
- [ ] `npm run build` 通过

# Tier 2: Full QA Checklist

**正式发布前**完整执行。Must-run 已覆盖的项目不再重复，此处为补充项。

---

## 1. 主链管理（补充）

### 1.1 边界验证
- [ ] 空名称不可创建（有错误提示）
- [ ] 触发动作为空不可创建
- [ ] 专注时长 ≤ 0 不可创建

### 1.2 长度统计
- [ ] 多次完成任务后，最佳长度 = max(各次完成时的当前长度)
- [ ] 中间有过清零时，最佳长度仍保持历史最高值

---

## 2. 正式任务（补充）

### 2.1 全局互斥
- [ ] 已有进行中任务时，无法启动另一个任务（有提示）
- [ ] 已有进行中预约时，无法启动正式任务（有提示）

### 2.2 调试记录
- [ ] 失败时选择调试分类（如「触发动作太重」），确认后记录生效
- [ ] 可在 History 中看到调试分类

---

## 3. 辅助链（补充）

### 3.1 全局互斥
- [ ] 已有进行中预约时，无法再创建预约（有提示）
- [ ] 已有进行中正式任务时，无法创建预约（有提示）

### 3.2 确认窗口守卫
- [ ] 确认窗口结束前，不可裁决（有提示「确认窗口尚未结束」）

### 3.3 辅助链判例化
- [ ] 待裁决状态下选择判例化 → 辅助链长度保留
- [ ] 判例出现在协议边界，标签为「辅助链」

---

## 4. 判例库（补充）

### 4.1 编辑守卫
- [ ] 已废止判例不可编辑（有错误提示）
- [ ] 二次废止不改变 retired_at 时间

### 4.2 历史保留
- [ ] 废止判例相关的历史事件仍显示判例标题

---

## 5. RSIP 定式树（补充）

### 5.1 边界验证
- [ ] 空标题不可创建
- [ ] 父定式不存在时不可创建子定式

### 5.2 定式复盘面板
- [ ] 显示子定式数量、活跃子定式数量
- [ ] 显示回滚事件次数
- [ ] 显示最近一次熄灭备注（含用户自定义文本）
- [ ] 显示事件历史列表

### 5.3 定式编辑
- [ ] 可编辑标题和执行说明，保存后生效
- [ ] 空标题编辑不可保存

---

## 6. Dashboard（补充）

### 6.1 状态切换全路径
- [ ] 「无活动」→ 启动预约 →「预约倒计时」
- [ ] 「预约倒计时」→ 到期 →「预约确认窗口」
- [ ] 「预约确认窗口」→ 到期 →「预约待裁决」
- [ ] 「预约待裁决」→ 完成裁决 →「无活动」
- [ ] 「无活动」→ 启动正式任务 →「任务进行中」
- [ ] 「任务进行中」→ 任务失败待裁决 →「任务待裁决」
- [ ] 「任务待裁决」→ 完成裁决 →「无活动」

### 6.2 RSIP 摘要
- [ ] 总定式数正确
- [ ] 活跃 / 非活跃数正确
- [ ] 最新事件显示正确

---

## 7. History（补充）

### 7.1 事件显示完整性
- [ ] CTDP 事件显示类型标签、链名、时间、结果、判例关联
- [ ] 辅助链事件显示类型标签、链名、时间、结果、判例关联
- [ ] RSIP 事件显示类型标签、定式名、时间、事件类型

### 7.2 筛选
- [ ] 按事件类型筛选（focus / reservation / rsip）— 每种独立验证
- [ ] 按结果筛选（success / failed / precedent）— 每种独立验证
- [ ] 按链筛选 — 仅显示该链相关事件
- [ ] 组合筛选（类型 + 结果）— 交集正确

---

## 8. Settings（补充）

### 8.1 持久化
- [ ] 修改设置 → 关闭应用 → 重新打开 → 值保持不变

### 8.2 生效验证
- [ ] 修改默认专注时长 → 创建新链 → 默认值匹配
- [ ] 修改辅助链确认窗口时长 → 创建预约 → 确认窗口时间匹配
- [ ] 修改默认预约时长 → 创建新链 → 辅助链延迟匹配

### 8.3 在线数据库恢复
- [ ] 选择备份 A 后确认页显示 A 的原始路径与统计；将原路径替换为有效备份 B 再确认，最终恢复内容仍为已检查的 A
- [ ] 点击「取消」或「重新选择」后，一次性恢复预览被清理，原始备份字节保持不变
- [ ] 带 `-wal`、`-shm` 或 `-journal` 的源文件被拒绝；在读取快照固定后才出现 sidecar 也必须被拒绝
- [ ] Windows：应用保持运行时，从数据集 B 恢复备份 A，统计和页面立即显示 A
- [ ] 恢复前安全快照可打开且包含数据集 B
- [ ] 在安全快照创建后强制主 staging→live 复制失败，live 仍为 B，安全快照仍可独立打开恢复
- [ ] 损坏、缺表、缺列、更高版本和当前 live 数据库自身均在 live 改动前被拒绝
- [ ] 连续快速恢复两次生成不同安全快照
- [ ] 外部连接持锁时恢复清晰失败或等待成功，live 不出现部分覆盖
- [ ] 恢复成功但统计刷新失败时，数据库信息区域显示「重试加载数据库统计」操作
- [ ] 过期的任务 staging 主文件及孤立 `-wal`/`-shm`/`-journal` 会清理；近期文件和无关名称保持不变
- [ ] 备份内进行中或逾期 CTDP 会话恢复后收敛到正确状态

---

## 9. Build 后检查

### 9.1 安装包验证
- [ ] `npm run tauri build` 成功（在 master 分支执行）
- [ ] 安装包可以正常安装
- [ ] 安装后应用可以正常启动
- [ ] Dashboard 正常显示
- [ ] 可以进行基本的链创建和任务操作

### 9.2 干净环境
- [ ] 删除/重命名 `protocol.db`，启动应用
- [ ] 确认数据库自动创建
- [ ] 确认初始设置值（专注 25min、预约 15min、确认窗口 3min）
- [ ] 确认无报错或崩溃

### 9.3 旧数据库升级
- [ ] 用前一版本的 `protocol.db` 启动新版本
- [ ] 确认应用正常启动，现有数据完整
- [ ] 确认 schema 迁移无报错
