# Protocol 日冕 UI 重设计规范

日期：2026-06-04 | 版本：v0.4.0

## 目标

从设计语言层面重构整体 UI，解决当前界面单调、重点不突出、缺乏操作引导的问题。

## 设计理念

暗色中，一束克制而精准的暖金光芒。不喧哗，但有温度。

核心理念：**一种强调色 + 两种字体 + 三个视觉权重层级 + 精准的留白**。

## 色彩系统

```
基底黑   #0b0b0d    页面背景
卡片黑   #131316    卡片、面板底色
悬浮灰   #1a1a1f    悬停态、输入框底色
边线灰   #252528    分割线、卡片边框

正文白   #f0ede6    标题、正文
辅助灰   #8c8982    辅助说明
弱化灰   #545250    禁用态、占位符

光冕金   #df9a3c    唯一强调色
金悬停   #eba845
金10%    rgba(223,154,60,0.10)
金边框   rgba(223,154,60,0.30)

成功绿   #6ba882    完成
警示橙   #c98a46    待裁决
失败红   #b8544a    断链
```

## 字体系统

| 用途 | 字体 | 风格 |
|------|------|------|
| 标题 / 大数字 | DM Sans | 几何无衬线 |
| 中文正文 | PingFang SC | 中性清晰 |
| 等宽数字 | JetBrains Mono | 精确 |

## 空间规则

- 页面内边距：40px 44px
- 卡片间距：20px
- 卡片内边距：20px 24px
- 内容最大宽度：880px
- 侧边栏宽度：200px

## 动效规范

- 页面进入：fade-in + translateY(6px)，0.3s
- 悬停：边框色 + 底色过渡，0.2s
- 按钮点击：scale(0.97)
- 状态切换：金色 glow 过渡

## 关键页面改造

### Dashboard
- 当前状态横幅全宽金色左边框，最突出
- 核心指标大号 DM Sans 数字，视觉权重最高
- 次要指标缩小，放第二行
- 空状态展示引导文案

### Sidebar
- 去掉图标外框，纯文字 + 金色细线指示当前页
- 选中项左侧出现 2px 金色竖线

### 链详情
- 神圣座位面板金色左边框突出
- 协议边界用时间线样式
- 主操作按钮金色实心，次要操作幽灵按钮

### 专注计时器
- 数字 96px DM Sans
- 进行中状态微弱金色光环
- 完成瞬间光环闪亮

### RSIP 定式树
- 树形缩进明显，父子关系细线连接
- 激活节点金色圆点，非激活灰色

## 实现范围

- 全局 CSS 变量与基础样式重写
- 所有页面组件适配新设计语言
- 侧边栏组件重设计
- 全局聚焦按钮适配
- 删除旧 CSS 中不再使用的样式

## 不变更

- 组件逻辑和业务功能
- 路由结构
- 数据库和后端
- TypeScript 类型定义
