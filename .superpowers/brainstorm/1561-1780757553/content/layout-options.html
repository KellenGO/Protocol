RSIP 页面构图 — 两种方案

核心原则：创建定式 = 动作 → 按钮展开；定式树 + 事件 = 信息 → 始终可见

方案 A — 平衡双栏

定式树（左 60%）+ 紧凑事件时间线（右 40%），创建按钮在顶部操作栏

方案 A 优点

  • 定式树和事件各占一栏，视觉平衡
  • 创建按钮在顶部操作栏，不占内容区
  • 事件列表紧凑横向排列，不抢定式树注意力
  • 整体结构清晰：操作→指标→内容双栏

方案 A 缺点

  • 事件列表在右栏，树少时右栏仍占空间
  • 适合中大型屏幕，窄屏需堆叠

方案 B — 树为主体，事件横向时间线置底

定式树独占全宽主区域，底部一条横向事件时间线，创建按钮悬浮

方案 B 优点

  • 定式树是全页主角，不受侧栏干扰
  • 事件时间线紧凑不占地
  • 浮动创建按钮视觉轻量
  • 适合树节点较多的场景

方案 B 缺点

  • 事件信息密度低（横向滚动可读性一般）
  • 浮动按钮可能遮挡内容
  • 创建定式的关联上下文（父定式选择）离树较远
